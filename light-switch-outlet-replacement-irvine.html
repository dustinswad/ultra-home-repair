Common questions

Planning your switch and outlet refresh.

Can you replace just one switch or outlet?

Yes. I can replace one switch, outlet or GFCI, several devices in a room, or devices throughout the home.

Do I need to buy the switches and outlets?

Either option works. I can install devices you supply, or we can discuss providing standard replacement devices for the approved project.

Can you replace an existing electrical box?

Yes, an existing device box can be replaced when needed as part of the project. This service does not include installing new wiring.

Do you replace GFCI outlets?

Yes. I replace existing GFCI receptacles and can install a GFCI device at an existing compatible outlet location. This service does not include a new circuit or new wiring.

Do you install dimmers and smart switches?

Yes. I can install compatible dimmers and smart switches at existing switch locations. I confirm device and wiring compatibility before installation.
