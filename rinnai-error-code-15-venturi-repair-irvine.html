No hot water and an error code?

What does Rinnai Error Code 15 mean?

Rinnai calls Code 15 “Venturi Control.” The code identifies a diagnostic path, not one universal failed part. Code 17 is a different Venturi-blockage fault, compared below.

If the display shows Code 15

Rinnai defines Code 15 as Venturi Control. The service path can involve the Venturi motor and control device, wiring, fan operation, and airflow. In the real repair documented below, the Venturi control disc was not opening and closing correctly.

If the display shows Code 17

Rinnai defines Code 17 as Venturi Blockage. Diagnosis can include the condensate path, combustion-air intake, exhaust, silencer, and Venturi before the obstruction is identified and the applicable reset is completed.

Safe first checks

  1. Write down the exact code and model number.
  2. Try one normal power restart.
  3. From the ground, check the outside vent termination for an obvious obstruction.
  4. Do not remove the cover or disassemble the Venturi.

Related—but not interchangeable

Rinnai Code 15 versus Code 17

Both codes point toward the Venturi system, but Rinnai defines them differently. The displayed code, exact model, and test results determine the correct service path.

Code 15

Venturi Control

Rinnai’s troubleshooting material directs the technician to evaluate the Venturi control, related wiring and motor operation, fan operation, and airflow. This documented repair involved a control disc that was not moving properly.

Code 17

Venturi Blockage

Rinnai identifies Code 17 as a Venturi blockage. The diagnostic path includes applicable condensate, intake, exhaust, silencer, and Venturi obstruction checks rather than assuming it is the same fault as Code 15.

Why flushing still matters

Scale can make the heater work harder—but a flush is not a Code 15 or 17 repair.

Mineral scale builds up on the water side of the heat exchanger. Because that buildup reduces heat-transfer performance, the heater may take longer to deliver the set temperature and may operate longer to meet the same hot-water demand. Regular flushing removes water-side mineral buildup and helps preserve the unit’s performance and efficiency.

Important: scale buildup does not prove that it caused the Venturi fault. Code 15 and Code 17 still require a separate Venturi and combustion-system diagnosis. If the heater is also overdue for maintenance, Dustin can evaluate the error code and address the flush as a separate service.

Common questions

Rinnai Venturi Repair Questions

What does Rinnai Code 15 mean?

Rinnai identifies Code 15 on applicable SENSEI models as Venturi Control. Diagnosis should start by confirming the exact model and following its applicable technical information.

Does Code 15 always require a new Venturi or gas-valve assembly?

No single repair decision applies to every Code 15. Rinnai’s published sequence includes electrical, wiring, airflow, fan, and Venturi checks and may direct assembly replacement. In this documented repair, Dustin restored the existing control disc’s movement and avoided replacing the complete assembly.

Are Code 15 and Code 17 the same?

No. Rinnai calls Code 15 “Venturi Control” and Code 17 “Venturi Blockage.” They involve related equipment, but they are distinct diagnostic codes.

Can I fix Rinnai Code 15 or Code 17 myself?

You can record the code, try one normal restart, and look at the outside vent termination from the ground for an obvious obstruction. Do not open the unit or disassemble its Venturi or gas-control components. If the code remains or returns, arrange professional diagnosis.

Will flushing fix Code 15 or Code 17?

Not by itself. A standard descaling flush removes mineral buildup from the water circuit; it does not directly repair a Venturi control or blockage fault. Scale can reduce heat-transfer performance and may make the heater operate longer to reach its set temperature, so flushing remains important maintenance. The displayed Venturi code still needs its own diagnosis.

Can a homeowner open the Venturi assembly?

No. The Venturi is part of a gas-fired appliance’s combustion system. The photos on this page document professional repair work; they are not disassembly instructions.
