What Rinnai Code 17 Means

Rinnai identifies Code 17 on applicable SENSEI tankless models as a venturi blockage. Diagnosis begins with the condensate drain and complete vent path before the venturi is inspected for debris or obstruction.

Rinnai's diagnostic sequence

  • Verify the condensate drain is working properly
  • Inspect the combustion-air intake, exhaust chamber and vent termination
  • Inspect the venturi for blockage or debris
  • Confirm the exact model and applicable service procedure
  • Identify any additional component or control problem

What you can safely check

  • Confirm the heater has power
  • Check the outside vent termination from the ground for an obvious obstruction
  • Do not open or alter the sealed combustion system
  • Try one normal restart
  • Call for diagnosis if Code 17 remains or returns
Do not bypass the code. The venturi is part of the combustion system. Repeated resets or unqualified disassembly can create additional problems. If you smell gas, leave the area and contact the gas utility or emergency services from a safe location.

Rinnai Code 17 Questions

Does Code 17 mean the heater must be replaced?

No. The code identifies a diagnostic area, not an automatic need for full replacement. The unit and applicable components must be tested.

Will flushing fix Code 17?

No—not by itself. Code 17 on applicable SENSEI models commonly requires inspection and cleaning of the venturi assembly. A water-side descaling flush is a separate maintenance service.

Do you work on condensing Rinnai units?

Yes. Ultra Home Repair services both condensing and non-condensing residential tankless systems.

Can I keep resetting Code 17?

One normal restart can confirm whether the condition was temporary. If the code remains or returns, the safer course is to diagnose the cause rather than repeatedly clearing it.
