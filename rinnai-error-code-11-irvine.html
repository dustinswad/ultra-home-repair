What Rinnai Code 11 Means

Rinnai identifies Code 11 as a no-ignition condition. The code tells us where to begin, but it does not identify one universal failed part. Proper diagnosis matters because ignition depends on gas supply, airflow, spark, flame sensing, wiring and the unit's controls working together.

Common areas to diagnose

  • Gas supply, shutoff position and operating pressure
  • Igniter, flame rod and related wiring
  • Intake and exhaust venting
  • Gas valve and combustion components
  • Control signals and model-specific conditions

What you can safely check

  • Confirm the heater has power
  • Confirm the gas shutoff handle is open
  • See whether another gas appliance operates
  • Check the exterior vent termination from the ground for an obvious obstruction
  • Try one normal restart; call if the code returns
Smell gas? Do not troubleshoot or reset the heater. Leave the area and contact the gas utility or emergency services from a safe location.

Rinnai Code 11 Questions

Does Code 11 mean my Rinnai needs to be replaced?

No. Code 11 is an ignition failure, not a declaration that the entire heater has failed. The cause and condition of the unit must be diagnosed.

Will flushing fix Code 11?

Not automatically. A flush addresses mineral scale in the water side of the heat exchanger. Code 11 can have gas, ignition, sensing, venting, wiring or component causes, so Dustin diagnoses the problem before recommending work.
