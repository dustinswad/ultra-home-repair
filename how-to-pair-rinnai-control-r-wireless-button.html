Rinnai recirculation guide

Pair the Rinnai Control-R wireless push button

This guide covers the older rectangular RWMPB01 button that flashes three times while pairing with the black Control-R module. Once paired, one press requests hot-water recirculation before you open the faucet.

First, make sure this is your button

Rinnai has sold more than one wireless recirculation button. The pairing sequence, battery and indicator lights are not identical.

Older RWMPB01 covered here

Rectangular white button, black Control-R module, two CR2450 batteries, and the familiar “flashes three times” pairing sequence.

Newer RPB200 is different

The newer button uses one CR2032 battery and flashes red, yellow or green. Follow the RPB200 instructions instead of the three-flash procedure below.

Compatibility matters: the older RWMPB01 button works with a Control-R module and a compatible Rinnai tankless water heater with recirculation capability. Pairing the button does not add a pump or recirculation loop to a system that does not already support one.

How to pair the rectangular Rinnai wireless button

The module gives you about five minutes after entering pairing mode. If the window expires, simply start again at step three.

Leave the water heater powered

The Control-R module needs power during pairing. Confirm the module is connected to the water heater and has an illuminated status light.

Check the push-button batteries

Remove the button cover and confirm that two CR2450 coin batteries are installed with their positive terminals aligned correctly. Refit the cover after checking them.

Put the module in pairing mode

Press and hold the Connect button on the black Control-R module until the module LED turns green. Release the Connect button.

Pair the wireless button

Within five minutes, press and hold the white wireless button. Keep holding until its light flashes three times and then begins rapidly flashing. Release the button.

Wait for the module to leave pairing mode

When pairing succeeds, the module flashes green and returns to its previous status color—normally blue when connected to the internet or red when offline.

Test the button once

Press and release the wireless button. During normal operation, the module LED should quickly flash green three times to confirm it received the recirculation request.

What the module lights mean

Green while pairing

The module is waiting for an accessory. After a successful pairing it should return to the color it showed before pairing.

Blue afterward

On the older module, blue indicates that it is connected to the internet. Internet access is separate from the direct button-to-module connection.

Red afterward

Red indicates that the older module is not connected to the internet. A paired wireless button can still operate because it communicates directly with the module.

Normal button confirmation: when you press the paired button, watch the module—not just the pump. Three quick green flashes from the module confirm it received the request.

If it flashes but does not finish pairing

Module stays flashing green

The module is probably still in pairing mode. Let the five-minute window expire, check the button batteries, and repeat the process from the Connect button.

Button does not flash

Recheck both CR2450 batteries, their polarity and contact. Replace weak batteries as a pair before trying again.

More than one button

Re-enter pairing mode for each accessory. Pair one button at a time rather than trying to add several during the same pairing window.

Module flashes, pump does not run

If the loop is already warm or the system is in a required dormant period, pump activation can be delayed even though the request was received.

Module was replaced

Buttons are paired to the module. If the module is replaced, each wireless button must be paired again.

Wrong button generation

A round RPB200 follows a different sequence. Do not use this older RWMPB01 procedure if the button uses one CR2032 battery.

How the button works after pairing

Pressing the button requests recirculation so heated water moves through the recirculation loop before the faucet is opened. Rinnai says the cycle stops after five minutes or when the water reaches the set temperature.

It may not run every time: if the pump recently operated and the loop is still warm, the system may delay or skip another pump cycle. That can be normal and does not necessarily mean the button lost its pairing.

Rinnai Wireless Button Questions

Does the button need my home Wi-Fi?

No. Rinnai says the wireless push button communicates directly with the module. The module can be offline from the internet and still receive a properly paired button request.

Why did the white button flash three times?

On the older RWMPB01, three flashes followed by rapid flashing are part of the pairing sequence. Release the button after those flashes and watch for the module to return to its previous status color.

What should happen when I press it normally?

The module LED should quickly flash green three times. That confirms the module received the recirculation request.

Why is the module red?

On the older Control-R module, red means it is not connected to the internet. That is not automatically a failed button pairing.

Can I pair more than one button?

Yes. Re-enter pairing mode and complete the process separately for each button.
